## 소개

안녕하세요, 전재경입니다.

마케팅과 콘텐츠 제작 일을 해왔고, 현재는 AI 서비스 개발 수업을 들으며 Python과 SQL을 공부하고 있습니다. 배우면서 불편했던 점을 작은 도구로 만들어 보는 데 관심이 있습니다.

프로젝트는 ChatGPT와 Codex의 도움을 받아 진행합니다. 필요한 기능을 정리하고 직접 사용하면서 수정하고 있으며, 만들어진 코드의 동작 원리도 함께 익히고 있습니다.

## 만들고 있는 것

### [Astara DB Studio ↗](https://github.com/wjsworud1025/myslq_study_tool)

MySQL을 공부하며 시작한 한국어 SQL 학습 도구입니다. SQL 편집과 실행에 용어 설명, AI 도움말, 실습 기능을 붙이고 있습니다.

AI의 도움으로 구현하고, 수업과 실습에서 사용하며 불편한 점과 오류를 고쳐 나가는 개인 프로젝트입니다.
